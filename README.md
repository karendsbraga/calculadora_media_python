# Projeto Sistema de Calculo Média de Notas

## Sistema de Cálculo de Média Escolar 🎓
Desenvolvi um sistema recebe notas de duas avaliações, valida os dados de entrada, calcula a média final e exibe instantaneamente a situação do aluno (Aprovado ou Reprovado). Uma solução simples para otimizar o acompanhamento do desempenho escolar.
